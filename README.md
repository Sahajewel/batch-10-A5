# Donate Bangladesh - Charity & Donation Platform

A responsive donation and charity website built with HTML, CSS, and JavaScript, created in 2022 to support humanitarian causes in Bangladesh.

## 📋 Description

Donate Bangladesh is a web-based platform designed to facilitate charitable donations for various relief efforts in Bangladesh. The website allows users to contribute to multiple causes including flood relief, quota movement support, and other humanitarian needs. The platform features real-time donation tracking, modal confirmations, and an interactive user interface.

## ✨ Features

- **Multiple Donation Campaigns**: Support for various humanitarian causes
  - Flood Relief in Noakhali
  - Flood Relief in Feni
  - Aid for Injured in Quota Movement
- **Real-time Donation Tracking**: Live balance updates showing total donations
- **Donation History**: Track all contributions made
- **Interactive Modal System**: Confirmation messages after successful donations
- **Account Balance Management**: Personal balance tracking system
- **Responsive Design**: Fully functional on mobile, tablet, and desktop
- **Blog Section**: Information and updates about causes
- **Dynamic JavaScript**: Real-time calculations and updates
- **User-friendly Interface**: Clean and intuitive donation process
- **Donation Cards**: Visual representation of each cause with descriptions

## 🚀 Technologies Used

- **HTML5**: Structure and semantic markup
- **CSS3**: Styling, layouts, and responsive design
- **JavaScript (ES6)**: Interactive functionality and DOM manipulation
  - Event handling
  - Dynamic content updates
  - Modal system
  - Form validation
  - Local calculations

## 🎨 Key Features in Detail

### Donation System
- Each cause has a dedicated donation card
- Users can enter custom donation amounts
- Real-time balance validation
- Instant balance deduction upon donation
- Success confirmation modal

### Account Management
- Starting balance: 5500 BDT
- Live balance display in header
- Automatic balance updates after donations
- Insufficient balance prevention

### Success Modal
- "Congrates" (Congratulations) message
- Display of donated amount
- "You have Donated for HumanKind Successfully" confirmation
- Close button to return to main page

### History Tracking
- Toggle between Donation and History views
- Record of all donations made
- Details of amount and cause
